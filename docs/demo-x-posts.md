# Real X posts for the fact-check demo

35 approved posts. Post texts checked against the live corpus on 21 November 2026. Use the public permalinks below in Chrome with the extension loaded. The cards appear under the original post and on the Politics timeline. Approved posts also render in **History → Bookmarks** when saved there.

The fact checker compares each post with the corpus and shows the specific evidence statement, in English. Facts written in Spanish carry a reviewed English `statement_en` for display; retrieval and verdicts still use the original text. **Insufficient information** means it found no direct evidence. **Inconclusive** can still show a source when the post mixes a supported fact with claims or framing the corpus does not settle. Every card is checked live on each load, with no cached verdicts, and shows how long the check took.

## YouTube video

[Castilla y León Televisión — SMI at €1,286 and public pay +5% in 2027](https://www.youtube.com/watch?v=VhiCa_4wmsU) (69 s, Spanish). Open it as a `watch` page, not from the Shorts feed. Click the extension icon, pick **Español** and press **Start checking**, then play the video from 0:00. Tab audio goes to OpenAI live transcription, the API extracts the claims, and each card appears in the call panel about 3–5 seconds after its sentence ends. The facts behind it are in `data/demo/video-smi.json`, and the snapshot below includes them.

| Time | What is said | Panel verdict |
| --- | --- | --- |
| 0:00 | The minimum wage rises €65 a month, €910 a year | True |
| 0:07 | It reaches an estimated 13.6% of employees, up to 2.7 million people | True |
| 0:16 | A 5.3% rise, to €1,286 gross a month in 14 payments | True |
| 0:21 | A decree exempts it from income tax | Likely true or Neutral (varies by run) |
| 0:27 | From 2027, minimum-wage earners pay no income tax from their first payslip | True |
| 0:39 | The tax deduction tapers off up to €23,172 | True |
| 0:46 | Civil servants will be paid 5% more next year | Neutral |

The 5% is Neutral on purpose: the sources show 4.5% for 2027 plus a conditional 0.5% still owed for 2026, two separate rises. The live transcription sometimes mishears a figure ("1.266" for 1,286, "2017" for 2027, "3,6%" for 13.6%), and that card then comes back false. It happened in about one sentence in ten across nine runs, so do a rehearsal run first, and replay if a red card appears that the video does not deserve. See [the run evidence](evidence/2026-11-21-youtube-video.md).

## Restore the demo corpus

The pgvector snapshot contains the public-source facts and their existing 1,536-dimensional `text-embedding-3-small` vectors. It upserts by fact ID and requires no embedding API calls during import. Live claims still need a project OpenAI key for query embeddings and Decisions.

```bash
npm ci
cp .env.example .env  # set OPENAI_API_KEY in .env
docker compose up -d --wait db
npm run build
npm run db:migrate
docker compose exec -T db psql -U factcheck -d factcheck -v ON_ERROR_STOP=1 < data/demo/corpus.pgvector.sql
npm start
```

In `chrome://extensions`, enable Developer mode and load the unpacked `apps/extension/dist` directory. Open one of the public X permalinks above. If you already have the extension installed, click Reload on its card (it should read version 0.4.0) and refresh X. Restore the snapshot after `npm run db:migrate`, which adds the `statement_en` column it fills.

`data/demo/x-posts.json` controls the approved Bookmarks posts. Update it and refresh X after editing; the extension loads the list from the local API.
